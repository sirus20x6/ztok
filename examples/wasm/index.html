ztok wasm demo

In-browser BPE tokenizer. Loads ztok_browser.wasm (~310 KB, built with WebAssembly SIMD128 enabled), parses a tiktoken vocab in the page, encodes locally — no network round-trip.

1. Load vocab

Pick a .tiktoken file. cl100k_base.tiktoken from the openai/tiktoken repo works as-is. The cl100k pre-tokenizer is hard-wired (so this demo expects a cl100k-style vocab).
