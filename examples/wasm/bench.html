ztok-wasm vs tiktoken-js

Single-threaded, in-browser, same corpus through both encoders. ztok is a Zig 0.16 BPE engine cross-compiled to wasm32-freestanding (~310 KB ungzipped, 109 KB gzip), with the WebAssembly SIMD128 proposal enabled so the BPE merge loop's min-scan uses i32x4.min_u opcodes. tiktoken-js is OpenAI's reference TS port. Both consume the same cl100k_base.tiktoken file, so the merge tables are bit-identical.

1. Vocab

Pick cl100k_base.tiktoken (get it from huggingface.co/Xenova/openai-cl100k_base or the openai/tiktoken repo). Both engines load from this exact byte buffer.
